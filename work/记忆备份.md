Windows PowerShell (5.1) 右键运行 .ps1 文件时支持中文的关键方法：

## 问题
Windows PowerShell 默认用系统 ANSI 编码（中文系统为 GBK）解析脚本文件。UTF-8 无 BOM 的 .ps1 文件中，中文字符会被错误解析为 GBK，导致乱码、字符串引号/方括号等语法被破坏，出现"数组索引表达式丢失或无效"、"字符串缺少终止符"等错误。

## 解决方案：保存为 UTF-8 BOM 编码

### 方法一：使用 PowerShell 写入（推荐，CodeBuddy 可用）
```powershell
# 单引号 here-string 保留内容原样，Out-File -Encoding utf8BOM 写入
$f = "path/to/script.ps1"; @'
# -*- coding: utf-8 -*-
Write-Host "[中文消息] 测试..."
'@ | Out-File -FilePath $f -Encoding utf8BOM
```

### 方法二：使用 .NET 方法
```powershell
$utf8Bom = [System.Text.UTF8Encoding]::new($true)
[System.IO.File]::WriteAllText("path/to/script.ps1", $content, $utf8Bom)
```

### 方法三：手动加 BOM（已有 UTF-8 文件）
```powershell
# 读取全文，前置 BOM 字节，写回（注意：是前置，不能 Skip）
$bom = [System.Text.UTF8Encoding]::new($true).GetPreamble()  # EF BB BF
$all = [System.IO.File]::ReadAllBytes($f)
[System.IO.File]::WriteAllBytes($f, $bom + $all)
```

## 注意事项
- CodeBuddy 的 `write_to_file` 工具写入的是 UTF-8 无 BOM，需要后续用上述方法添加 BOM
- `execute_command` 中的 here-string 必须用单引号 `@'...'@`（`@` 后无空格），不能用双引号版本
- 验证 BOM：`[System.IO.File]::ReadAllBytes($f)[0..2]` 应为 `EF BB BF`
- `# -*- coding: utf-8 -*-` 声明本身对 PowerShell 无效，但可保留作为编辑器提示
